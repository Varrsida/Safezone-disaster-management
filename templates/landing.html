Problem Definition

Addressing Vulnerable Settlement Risk & Relocation

Communities living in flood-prone, landslide-prone, coastal, or cloudburst-prone regions face repeated risk to life and infrastructure. Identifying which habitations require urgent attention and determining where residents can be safely relocated requires integrating multi-hazard exposure, population vulnerability, and recipient site carrying capacity.

Core Capabilities

Why SafeZone?

Hazard Identification

Systematically identifies habitations exposed to landslides, floods, cloudbursts, and coastal erosion using multi-parameter hazard scoring.

Vulnerability Assessment

Evaluates community vulnerability by incorporating elderly/children ratios, road accessibility, elevation, and emergency service distances.

Safe Location Assessment

Evaluates candidate relocation grounds for low hazard exposure, infrastructure availability (water/power), and proximity to essential services.

Relocation Prioritization

Computes carrying capacity vs. population demand to generate actionable, ranked relocation recommendations for emergency planners.

Technology Stack

Built with Core Technologies

HTML5 / CSS3 / Vanilla JS

Clean, framework-free web interface featuring responsive grids, modal dialogs, and custom styling without Bootstrap or Tailwind.

Python & Flask

Lightweight backend server managing request routing, session authentication, risk mathematical logic, and RESTful API endpoints.

Pandas & NumPy

High-performance data manipulation for synthetic feature vector processing, distance matrix calculations, and risk index normalization.

Scikit-learn & Joblib

RandomForestClassifier model trained on 5,000 synthetic hazard records to output risk classification probabilities with saved model persistence.

SQLite Database

Relational database storing habitations, hazards, safe zones, capacity status, relocation plans, and alert logs.

Leaflet.js & Chart.js

Interactive client-side map rendering for risk-colored habitation markers and lightweight summary visualization charts via CDN.
